# SAI Releases

Официальный публичный канал обновлений SAI.

Здесь публикуются только готовые установочные пакеты, контрольные суммы и
описания изменений. Исходный код, конфигурация магазина, ключи доступа,
локальные базы данных и пользовательские файлы в этот репозиторий не попадают.

## Каналы

- обычный GitHub Release — проверенная production-версия;
- GitHub Pre-release — тестовая development-версия, устанавливаемая только
  вручную на компьютере разработчика.

Программа должна принимать production-обновление только после проверки
версии, канала и SHA-256 установочного пакета.
