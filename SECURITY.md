# Безопасность обновлений

Не публикуйте здесь исходники SAI, токены, пароли, конфигурацию магазина,
базы данных, журналы, браузерные профили и пользовательские документы.

Каждый установочный пакет должен сопровождаться манифестом с номером версии,
каналом выпуска, именем файла, размером и SHA-256. Production-релиз создаётся
только после прохождения полной приёмки SAI.
